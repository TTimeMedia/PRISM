# settings

Cross-cutting settings not owned by a single feature (e.g. app-wide preferences). Most settings screens live under features/you/ — see docs/SCREEN_BIBLE.md §9.

Reserved for a later milestone — see `docs/BUILD_STATUS.md` for the
implementation checklist and `docs/MASTER_BUILD_SPEC.md` §28 for the
development roadmap. This directory intentionally has no implementation
yet; it exists so the feature can be added here without restructuring.
